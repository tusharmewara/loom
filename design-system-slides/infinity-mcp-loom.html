Infinity MCP + Loom

Extending the Loom Ecosystem as an MCP Tool Source

Connecting Infinity Code agents to Loom's shared skills, sessions, and auth via the stdio MCP server.

Loom v0.9.6 · Infinity Code (Hydro)

The Gap

Loom exposes a rich ecosystem (skills, MCP registry, sessions, auth vault) but only through its own CLI, daemon IPC, and TUI. Infinity Code agents cannot natively query or act on that state.

Loom surface

  • Shared skills registry
  • MCP server pool & health
  • Session export / import
  • Auth providers & grants

Infinity Code need

  • Tool sources via MCP
  • Background agent context
  • stdio server model

The Bridge

Loom already ships loom-mcp-server — a stdio JSON-RPC 2.0 MCP server exposing the ecosystem as tools. No changes to Loom required.

stdio JSON-RPC 2.0 · protocolVersion 2024-11-05

Configuration

User-level ~/.infinity/rap.json or project-level .infinity/rap.json, merged at startup.

{
  "tool_sets": [
    {
      "type": "mcp_server",
      "name": "loom",
      "command": ["loom-mcp-server", "--loom-dir", "~/.loom"],
      "env": {} 
    }
  ]
}

Loom MCP Tools

ToolPurpose
loom_list_skillsList shared skills in the ecosystem
loom_get_skillGet skill content by name
loom_list_mcp_serversList shared MCP server configs
loom_get_mcp_configGet merged MCP config
loom_save_sessionExport a session
loom_list_providersList auth providers
loom_get_credentialGet credential for a provider
Methods: initialize, tools/list, tools/call

Advantages

Zero Loom changes

loom-mcp-server already exists (crates/loom-mcp-server/src/main.rs).

Any MCP client

jcode, claude-code, opencode can all consume Loom tools.

User + project config

Per-repo LOOM_AGENTS_DIR support via merged rap.json.

Additive distribution

Loom reachable from Infinity Code background agents.

Disadvantages

Thin tool surface

7 list/get tools only — no exec, daemon, or workflow dispatch.

Credential exposure

loom_get_credential leaks vault secrets to any agent with tool access.

Two ecosystems

Rust (Loom) + JS/TS (Infinity Code) runtimes to maintain.

Redundancy

Layers over Loom's own IPC/daemon rather than replacing it.

Product Lineup Impact

Not a significant new product line. An additive integration point that makes Loom consumable as an MCP tool source for Infinity Code agents. The meaningful product play would be exposing Loom's full daemon/IPC (exec, dispatch, skills activation) through MCP — which the current server does not do.

Additive, not categorical

Recommendation

Adopt

Wire loom-mcp-server into Infinity Code for skill/session/auth reads.

Gate credentials

Omit or scope loom_get_credential; add ACL before exposing vault data.

Expand surface

Add exec, dispatch, and skills-activation tools for write paths.
