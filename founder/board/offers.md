# Offers lens

Score: 6/10 | Vote: FUND IF

## What is strong
- Dream outcome is crisp: start a task in one AI coding agent, finish in another without losing context. Real pain for poly-agent teams.
- $30/seat/month is an easy B2B price to sell; Stripe billing already wired (phase 6 complete).
- Enterprise add-ons (SSO, FIPS, audit) raise ACV and match how dev tools are actually bought (top-down, procurement-led).
- Local daemon means value works offline and is felt quickly once installed.

## What would kill it (top 3, most dangerous first)
1. Vitamin, not painkiller: most developers use one agent; context loss when switching tools is infrequent enough that they will not pay $30/month to prevent it. No evidence yet that anyone will pay (phases built, revenue not demonstrated).
2. Time-to-value is long: install a daemon, wire adapters for 11 agents, import sessions — effort is high before the dream outcome is felt. The value equation (dream outcome x likelihood / (delay x effort)) collapses if delay x effort is high.
3. Free/commoditized alternatives: Cursor, Codex, Copilot are converging on shared context and MCP; if context sharing becomes table stakes inside the agents themselves, Loom's offer is obviated.

## The questions I would ask the founder
- What % of target customers use 2+ AI coding agents daily? (/founder-consumer)
- What is CAC vs $30-seat LTV? (/founder-cfo)
- Has anyone paid yet, or only installed v0.12.0?

## If FUND IF: the conditions
- Paid pilot with 3+ teams using >=2 agents, converting to paying seats before scaling sales.
- Cut time-to-value: one-command install and one adapter that delivers context sharing, not 11 adapters up front.
- Define the paid wedge: which license-gated feature makes someone reach for a card on first use?
